- 無線 LAN：オフィス内など LAN の範囲内を高速に通信するもの。

# # CSMA/CA 方式 (Carrier Sense Multiple Access with Collision Avoidance)
- 同じ周波数で通信を共有する無線の媒体共有型の方式。
- 通信できる数には限りがあるので、CSMA/CA 方式によってデータを送信していい状態かを確認してランダムな時間 (バックオフとも呼ばれる) 待機してデータ送信を開始してコリジョンを回避する。

# # 無線 LAN を使用する際の注意点
- 利用者の移動性や機器の自由性を確保するために電波の性質を利用し広範囲に電波を受信できるようにしていることから、盗聴や改ざんのリスクも伴っている。
- 改ざんなどを防止するために通信を暗号化する技術が開発されている一方で、暗号を解読するようなツールも開発されている。
- 現在は AES ベースの暗号化プロトコルである WPA2 が普及している。
- 今後は WPA3 が普及していき、さらに認証された機器だけが無線 LAN を利用できるようなアクセス制御の技術も併用して安全に使用できるようにする必要がある。
- 無線 LAN は無免許で利用できる周波数帯を使用していて、電子レンジなどの周波数の影響によって通信速度が低下することもある。

# # WPA2 と WPA3
- Wi-Fi Alliance の認証プログラムである WPA (Wi-Fi Protected Access) を拡張して IEEE802.1l の必須部分を実装した規格で、AES ベースの暗号化プロトコルを採用。
- WPA3
    - WPA2 のセキュリティ機能をさらに拡張した規格。
    - 家庭や小規模なオフィスを対象とした WPA3-Personal では SAE (Simultaneous Authentication of Equals) を実装することでパスワード ベースの堅牢な認証を実現。
    - 大規模なオフィスには WPA3-Enterprise として、192 ビット セキュリティ モードを提供しさらにセキュリティが強化される。

# # 携帯電話の通信
- 携帯電話の通信はアクセスに存在しているキャリア回線の基地局からエッジ → コアなどに通信される。
- ローミング: 端末が移動すると基地局間で情報交換が行われること。

# # 公衆無線 LAN とその認証方法
- 公共施設などの Wi-Fi に接続するとき、どのユーザーが接続しようとしているのかを確認するため認証の通信を行う。

# # WiMAX (Worldwide interoperability for Microwave Access)
- マイクロ波を使用して企業や自宅へ無線接続する方式。
- DSL や FTTH といった通信事業者から終端の 1 区画 (ラストワンマイル) を無線で実現させる方式。
- 無線 MAN に属していて、大都市圏をエリアとする広域ネットワークをサポート
- IEEE802.16 で定義されているうちの一部で、携帯端末に対応した IEEE802.16e も存在。

# # Bluetooth
- IEEE802.11b/g と同様に 2.4 GHz の帯域を使用。
- バージョン 2 では 3 Mbps (実際は 2.1 Mbps) の伝送速度をもつ。
- 通信距離は電波強度により 1/10/100/400 m。
- 原則として最大 8 台まで接続可能。(1 台をマスター、他 7 台をスレーブでネットワークが構成される。ピコネットと呼ばれる)
- IEEE802.11b/g と電波が干渉して速度が低下する恐れがある。
- 携帯電話やイヤホンなど小型のデバイスなどを対象としている。
- 4.0 では省電力・低コストを実現するための Bluetooth Low Energy (BLE) が策定されて IoT デバイスなどで活用されている。

# # Zigbee
- 家電に組み込むことを前提として、低消費電力で短距離の無線通信を実現。
- 最大 65536 個の端末間を無線で通信する。
- 使用する周波数にも異なるが、日本で利用可能な 2.4 GHz 帯域では最大 250 kbps とされている。

# # LPWA (Low Power Wide Area)
- 明確な定義はないが、低消費電力かつ長距離通信可能なネットワークとして呼ばれ、IoT などで使用されるネットワークのことを指す。
- 特定小電力無線として無線局免許が必要なものとそうでないものに分かれる。
    - LoRaWAN: 標準化団体 LoRa Alliance によって仕様が公開されているオープンな規格で、免許が必要のない 920 MHz 帯域を使用。送信データは 11 バイトとなり、最大 10 km 程度のデータ通信が可能。自営でも構築できて LoRaWAN ゲートウェイを設置して LoRaWAN デバイスと通信する。
    - Sigfox: Sigfox 社独自の規格。免許が必要なく、920 MHz 帯域を使用。送信データは 12 バイトで LoRaWAN と異なり自営での構築ができず、Sigfox のサービス業者と契約して利用できる。
    - NB-IoT: LTE を利用。3GPP が 2016 年に Release13 で仕様化。上り 62 kbps、下り 21 kbps で半二重通信になる。携帯電話事業者との契約が必要。
